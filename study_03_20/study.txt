        + 위치 정보까지 함께 강조: 얼굴

패턴 인식의 역사
- AlexNet
    - 어떤 단점이 있었는데, 이걸 어떻게 해결했다.
    - => 활용할 때, 문제점 파악 용이?
이전 gradient * 활성화 함수 미분값 * weight => 계속 곱하다 보면(깊게 쌓을수록) 1보다 작아짐=> 기울기 소실이 일어남(ex.100개에서 0이되면 99가 다 죽음) 
    - ReLU로 음수를 바꿔서 기울기 소실을 줄임. 
    - drop out사용.
 drop out 
- 특정 weight가 과하게 강조되거나, 무시되는 현상을 줄이기 위해서 =>모든 레이어가 평등하도록
  에폭 돌릴때마다 랜덤한 간선을 무시하고 학습(레이어가 깊거질수록 무시하는 %가 높아짐)
  ex. 10% => 전체 중 10%를 무시

relu 단점:
= 음수를 죽이니까 정보가 사라짐.
 -> relu 이전, 이후를 같이 씀 이전에서 사라진 정보를 가져오고, 특징값들을 렐루 이후에서 가져오기

- ResNet 
- ReLU 써도, 깊게 쌓을수록 기울기 소실이 일어나긴 함.
  =>relu 이전, 이후를 같이 씀 이전에서 사라진 정보를 가져오고, 특징값들을 렐루 이후에서 가져오기(잔차를 연결) => ResNet원리

CNN 동작원리
- 데이터 하나하나가 채널
  => grb(컬러)는 3채널, 흑백(1채널)
- forward하면 연산 결과로 나오는ㄴ 특징지도(Feature map)의 크기가 줄어듦. 커널(필터)의 크기는 정한대로 고


커널
이미지 위를 슬라이딩해서 숫자를 곱하고 더하는  3x3, 5x5 크기의 작은 행렬.
필터
특정 하나의 특징을 추출하는 커널들의 집합
패딩
이미지 외곽에 특정값 (보통 0)을 채워 넣은 테두리 두르기
- 정보 보존: 합성곱을 하면 이미지 가장자리는 커널이 한 번씩밖에 못 훑고감. 중앙을 여러번 겹침.
            => 패딩을 주면 가장 자리 정보도 충분히 활용 가능
- 크기 유지: 합성곱 연산을 하면 결과물의 크기가 줄어듦. 층이 깊어질수록 이미지가 작아짐.
            => 입력과 출력의 크기를 똑같이 맞출 때 주로 사용(same padding)

pooling(max, min, avg등 있움)
- 특징을 압축해서 중요한 특징만 남기고 공간정보를 줄이자. (위치변화에 민감하게 만듦)
- 필요한(강조하고 싶은) 데이터만 남기고 다 버리자(최소화시키자)  => + 연산을 줄이기 위해서 
- max pooling 결과: 가로, 세로 크기가 절반으로 줄어듦. 4x4 => 2x2

flatten
- Ex) rgb 3개의 최종 필터를 하나도 합쳐서 한 줄로 만들기
- ex). 7(가로)* 7(세로) * 512(채널) = 25,088개의 숫자를 1차원 벡터로 변환.
=> 3D 형태의 데이터를 1D(vector)로 바꿔서 FC layer에 전달


fc layer
- 전체 다 연결해서(flatten으로 합친 것) 와이헷을 구함.
